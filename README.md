# Email Spam Classifier

This is a minor project that classifies emails as spam or ham (not spam) using Natural Language Processing (NLP) and the Multinomial Naive Bayes algorithm.

## Features
- Text vectorization using TF-IDF.
- Multinomial Naive Bayes classifier for spam detection.
- Simple and efficient text classification.

## How to run
1. Install dependencies: `pip install pandas scikit-learn joblib`
2. Run training script: `python train.py`
